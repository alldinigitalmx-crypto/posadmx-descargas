# POS Admx — Descargas

Punto de venta para tiendas de abarrotes, de **Admx** ([admxdev.com](https://admxdev.com)).

## Instalar en una computadora nueva

**[Descargar el instalador (última versión)](https://github.com/alldinigitalmx-crypto/posadmx-descargas/releases/latest/download/Instalar-POS-Admx.exe)**

- Windows 10 (1809) o Windows 11, de 64 bits.
- No hace falta internet para vender: cada caja trae su propia base de datos.
- Windows puede mostrar «Windows protegió su PC»: pulsa «Más información» y luego «Ejecutar de todas formas».

## Actualizaciones

Las cajas instaladas revisan aquí solas si hay una versión nueva, la bajan en segundo plano y la instalan al cerrar el programa.
No hay que descargar nada a mano. Las versiones anteriores están en [Versiones](https://github.com/alldinigitalmx-crypto/posadmx-descargas/releases).

Este repositorio solo guarda los instaladores y los paquetes de actualización.
